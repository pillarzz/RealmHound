# RealmHound Releases

Download the latest release from the [Releases page](https://github.com/pillarzz/RealmHound-releases/releases).

## Requirements

- Windows 10/11 (64-bit)
- [Npcap](https://npcap.com/#download) must be installed for packet capture

## About

RealmHound is a loot tracker for Realm of the Mad God.
